# AeroSpec Agent
## Trustworthy Hyperspectral Mission Design Copilot for Aviation

AeroSpec Agent is a tool-using mission-design agent that builds constrained hyperspectral band plans for aviation sensing goals.

## Why this is agentic AI (not a classifier/chat wrapper)
- Executes a 5-stage LangGraph workflow with structured state.
- Retrieves many candidate regions from local rules, then optimizes a band **set** under constraints.
- Runs deterministic verification for target coverage, conflicts, and confidence calibration.
- Emits transparent logs, warnings, assumptions, and alternatives.

## LLM backend and fallback
- **Default hosted reasoning backend:** Groq (`GROQ_API_KEY`, `GROQ_MODEL`).
- If key exists, Groq is used for mission interpretation normalization.
- If key is missing, app automatically runs in deterministic fallback mode.
- Wavelength recommendations are never directly generated by the LLM.

## Architecture
```text
User Input (Gradio)
  -> [1/5 Mission Interpreter]
  -> [2/5 Knowledge Retriever]
  -> [3/5 Constraint + Ranking + Band-set Optimization]
  -> [4/5 Verification]
  -> [5/5 Report Agent]
  -> Executive brief + cards + spectral plot + debug JSON
```

## Multi-target support
Targets are lists, not single labels. Examples:
- cloud + water
- water + vegetation
- cloud + water + moisture

## Band-set selection (high level)
1. Retrieve candidate spectral regions across all requested targets.
2. Deduplicate overlaps and preserve target tags.
3. Score candidates with transparent components (coverage, flux suitability, interpretability, robustness, context bonus, etc.).
4. Optimize selected set up to `max_bands` with diminishing-returns and overlap penalties.
5. Verify target coverage and constraint consistency.

## Setup
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

### Environment variables
- `GROQ_API_KEY` (optional)
- `GROQ_MODEL` (default `llama3-70b-8192`)

## Run locally
```bash
python app.py
```

## Run on Hugging Face Spaces
- Add `GROQ_API_KEY` in Space Secrets.
- Optionally set `GROQ_MODEL`.
- Launch with `python app.py` (or Spaces default command if configured similarly).
- Without key, deterministic fallback mode remains available.

## Extending spectral rules
Edit `data/spectral_rules.json` and add entries with:
- id
- wavelength range
- target tags
- rationale
- confidence
- caution
- reference
- optional context flag

These are seed demo rules, not exhaustive scientific truth.
